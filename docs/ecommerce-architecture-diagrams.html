Production infrastructure for 1k RPS: Multiple NestJS instances behind Nginx load balancer for horizontal scaling. PostgreSQL primary handles writes, while read replicas optimize product catalog queries. Redis provides caching and session management. Complete observability stack with Prometheus, Grafana, Loki, and Jaeger for monitoring and debugging.

Phase A (MVP): Minimal setup for launch, establish performance baseline. Phase B (Growth): Add load balancing and read replicas as traffic increases, introduce job queues. Phase C (Scale): Full deployment for 1k RPS with Redis cluster, advanced monitoring, and production hardening.

pie title Monthly Infrastructure Cost: $1,250 "App Servers (4x)" : 240 "PostgreSQL Primary" : 200 "PostgreSQL Replicas (2x)" : 200 "Redis Cluster" : 300 "Load Balancer" : 60 "Network/Storage" : 150 "Monitoring Stack" : 100

Monthly cost breakdown at full 1k RPS scale (self-hosted on Hetzner/OVH). Redis cluster is the largest expense due to high memory requirements for caching. This is 30% cheaper than AWS equivalent, but requires DevOps expertise. MVP phase costs ~$190/month, grows to $640 at 200 RPS, then $1,250 at 1k RPS.
